Stocktill — Multi-Store POS & Inventory SaaS

Full-stack SaaS

Point of sale and inventory for many stores on one platform, where each business only ever sees its own data. The barcode-scanner checkout works on desktop and on phones; owner, admin and cashier roles are enforced with Row-Level Security in PostgreSQL; billing runs on Stripe with a free trial; and it ships as a Docker container.

700+ tests in CI · RLS on 20/20 tables · 3 roles

  • Next.js
  • TypeScript
  • Supabase / PostgreSQL
  • Stripe
  • Docker
Live demo of Stocktill (opens in new tab) Code for Stocktill on GitHub (opens in new tab)

case-study/

  1. Problem

    Small shops run the counter on spreadsheets: stock drifts, cashiers can see margins they shouldn't, and nobody knows who changed what.

  2. Solution

    A fast register for any USB scanner or the keyboard alone, inventory with low-stock alerts and Excel import, reports, returns and an activity log.

  3. Technical decisions

    Tenant isolation and roles live in PostgreSQL RLS, not just the UI. Stock only changes through database functions that log every movement, and money is stored as exact decimals.

  4. Result

    A live public demo backed by unit, pgTAP, integration and Playwright end-to-end tests that run in GitHub Actions on every push.
