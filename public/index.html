About me

I'm a Software Engineering student who thinks end to end. On the front end, I turn ideas into fast, polished websites with HTML, CSS, JavaScript, Tailwind CSS and Bootstrap, and build app interfaces with React and TypeScript. On the back end, I've built and deployed a REST API in Python with FastAPI and PostgreSQL — with authentication, database-level security and automated tests — and I keep deepening my SQL and database design. I launch what I build myself, with custom domains and HTTPS. Open to freelance projects.
